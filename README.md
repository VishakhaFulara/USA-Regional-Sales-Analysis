# 🟦 USA Regional Sales Performance Analysis

## 📌 Overview
This project focuses on analyzing regional sales performance across the USA using an end-to-end data analytics approach. The objective is to uncover meaningful business insights, identify revenue-driving factors, and build an interactive Power BI dashboard to support data-driven decision-making.

---

# 🟦 The Problem
The company needed deeper visibility into regional sales performance, product demand, sales channels, and seasonal trends to optimize business strategy and improve revenue growth.

---

# 🟦 The Approach
- Processed and analyzed sales data using **Python, SQL Server, Excel, and Power BI**
- Performed **data cleaning, transformation, and exploratory data analysis (EDA)** using Python
- Executed SQL-based business analysis to uncover revenue, profit, and regional performance trends
- Designed a **Star Schema data model** in Power BI for efficient reporting and analysis
- Built a multi-page interactive dashboard to visualize KPIs, revenue trends, product performance, and geographic distribution

---

# 🟦 Dataset
The dataset contains sales transaction details, including:

### Key Columns
- Order Details (`order_number`, `order_date`)
- Customer & Product Information
- Region & State Data
- Revenue & Cost Metrics

# 🟦 Key Insights
- Wholesale channel generates approximately **54% of total revenue**
- West region contributes around **30% of overall revenue**
- January shows peak revenue trends across years
- Product 26 and Product 25 are the top revenue-driving products
- California contributes **19.5% of total revenue (~$228.8M)**
- West region has the **highest profit margin (~37.5%)**
